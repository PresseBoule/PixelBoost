# POSITIONNEMENT DE PIXELBOOST

PixelBoost propose principalement l’installation et la personnalisation d’agents web IA pour les entreprises.

Ces agents peuvent notamment :

- répondre automatiquement aux questions des visiteurs ;
- connaître les informations spécifiques d’une entreprise ;
- répondre sur les tarifs, services, horaires, règles, produits, conditions, disponibilités, etc. ;
- exploiter des informations provenant du site ou de sources de données externes ;
- consulter certaines disponibilités ou informations lorsque des calendriers ou bases de données sont connectés ;
- aider à qualifier les prospects ;
- récupérer certaines informations avant une prise de contact ;
- automatiser certaines demandes simples ;
- transmettre une demande à un humain lorsque nécessaire ;
- évoluer avec les besoins de l’entreprise.

Selon le projet, les agents peuvent être connectés à différentes sources ou services compatibles :
- site web ;
- calendriers ;
- formulaires ;
- bases de données ;
- API ;
- email ;
- autres outils métier lorsque cela est techniquement possible.

La création ou refonte de sites web peut toujours apparaître comme un service PixelBoost, mais elle doit devenir secondaire.

Le produit principal est désormais l’agent web IA.

Le design et la création de sites sont au service de cette offre.

# ANIMATIONS

Conserve uniquement les animations qui apportent quelque chose.

Réduis :

- les animations inutiles ;
- les transitions trop longues ;
- les éléments uniquement décoratifs ;
- les grandes zones vides servant seulement à montrer un effet visuel.

Les animations doivent servir :

- la compréhension ;
- la hiérarchie ;
- la narration ;
- la démonstration du produit.

Les animations doivent être fluides, légères et rapides.

Prévoir également un comportement compatible avec prefers-reduced-motion.
